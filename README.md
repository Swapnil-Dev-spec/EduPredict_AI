# EduPredict AI 🎓📊

An AI-powered Student Performance Prediction System built using Machine Learning and Streamlit.  
This project predicts student academic performance based on study habits and provides intelligent insights, recommendations, and visual analytics.

---

## 🚀 Live Features

- 📈 Student performance prediction using ML models
- 🧠 AI-based academic insights
- 🎯 Personalized study plan generation
- 📊 Interactive analytics dashboard
- 🏅 Performance indicators (badges system)
- 📉 Data visualization (graphs & trends)
- 🗂️ SQLite database integration for storing predictions
- 📜 Prediction history tracking
- 🎨 Modern UI with Streamlit

---

## 🧠 Machine Learning Models Used

- Linear Regression
- Random Forest Regressor

---

## 📊 Input Features

The model takes the following inputs:

- Study Hours per Day
- Attendance Percentage
- Sleep Hours per Day
- Previous Exam Marks

---

## 🎯 Output

- Predicted Final Score (0–100)
- Grade (A / B / C / F)
- Performance Level (Exceptional / Proficient / etc.)
- Academic Status (Pass / Fail)
- AI-generated insights & recommendations
